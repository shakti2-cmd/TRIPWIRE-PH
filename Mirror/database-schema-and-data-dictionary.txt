# Database Schema & Data Dictionary: TRIPWIRE-PH_DB_Master

This dictionary outlines the structure, column definitions, data types, and sample data for the five worksheets inside the central Google Spreadsheet: `TRIPWIRE-PH_DB_Master`.

---

## Tab 1: `sys_config`
Key-value configuration store for runtime credentials, sector bounds, and threshold parameters.

| Column | Name | Type | Allowed Values / Constraints | Example Value | Description |
| :---: | :--- | :--- | :--- | :--- | :--- |
| **A** | `config_key` | String | Non-empty unique string | `GEMINI_API_KEY` | Identifier name for configuration variable. |
| **B** | `config_value` | String | Valid format corresponding to key | `AIzaSyD-XYZ123456...` | Value read by Apps Script during execution. |
| **C** | `description` | String | Free text | `Google AI Studio API Key` | Developer note on variable usage. |

### Required Rows in `sys_config`:
- `GEMINI_API_KEY`: API token from Google AI Studio.
- `TELEGRAM_BOT_TOKEN`: Token issued by `@BotFather`.
- `TELEGRAM_CHAT_ID`: Destination Telegram channel or user ID.
- `NASA_MAP_KEY`: Self-service key for NASA FIRMS REST API.
- `OPENSKY_USER`: OpenSky Network registered username.
- `OPENSKY_PASS`: OpenSky Network registered password.
- `ALERT_THRESHOLD`: Integer minimum score to trigger dispatch (Default: `50`).
- `CRITICAL_THRESHOLD`: Integer minimum score for unmuted alarm (Default: `75`).
- `GEMINI_MODEL`: Configurable Google AI Studio model identifier (Default: `gemini-2.5-flash-lite`).
- `GEMINI_BACKUP_API_KEY`: Secondary Google AI Studio API key for automatic failover on HTTP 429/500 errors.

## Tab 2: `raw_telemetry`
Time-series ledger updated every 15 minutes. Each execution appends 5 rows (one per sector: `SEC-01` through `SEC-05`).

| Column | Header | Type | Format / Constraints | Example Value | Description |
| :---: | :--- | :--- | :--- | :--- | :--- |
| **A** | `timestamp` | Timestamp | ISO-8601 (`YYYY-MM-DDTHH:mm:ssZ`) | `2026-10-31T21:40:00+08:00` | Scheduled cycle execution timestamp. |
| **B** | `sector_id` | String | `SEC-01`, `SEC-02`, `SEC-03`, `SEC-04`, `SEC-05` | `SEC-02` | Monitored operational quadrant identifier. |
| **C** | `flight_count` | Integer | $\ge 0$ | `8` | Total active transponders inside bounding box. |
| **D** | `baseline_median` | Float | $\ge 0.0$ | `30.0` | Expected circadian median for current day/hour. |
| **E** | `z_score` | Float | Continuous | `-2.85` | Standard deviations from median. |
| **F** | `squawk_alerts` | Integer | $\ge 0$ | `1` | Count of active `7700` or `7600` squawks. |
| **G** | `firms_hotspots` | Integer | $\ge 0$ | `7` | Off-shore thermal points ($\text{FRP} \ge 85\text{ MW}$). |
| **H** | `ioda_outage_flag` | Boolean | `TRUE` / `FALSE` | `FALSE` | National macroscopic BGP drop detected. |
| **I** | `diplo_alert_flag`| Boolean | `TRUE` / `FALSE` | `FALSE` | Sovereign embassy evacuation directive active. |

## Tab 3: `sector_baselines`
Pre-calculated matrix of historical flight density medians. Used to calculate real-time Z-scores across all 5 sectors (840 total rows).

| Column | Header | Type | Format / Constraints | Example Value | Description |
| :---: | :--- | :--- | :--- | :--- | :--- |
| **A** | `sector_id` | String | `SEC-01`, `SEC-02`, `SEC-03`, `SEC-04`, `SEC-05` | `SEC-01` | Operational sector ID. |
| **B** | `day_of_week` | Integer | `0` (Sunday) to `6` (Saturday) | `1` (Monday) | Circadian weekly grouping. |
| **C** | `hour_of_day` | Integer | `0` to `23` (PHT / UTC+8) | `14` (2:00 PM) | Diurnal hourly grouping. |
| **D** | `rolling_median`| Float | $\ge 0.0$ | `45.2` | 14-day median airborne flight volume. |
| **E** | `std_deviation` | Float | $> 0.0$ | `6.1` | Historical standard deviation (or MAD). |

## Tab 4: `alert_dispatches`
Audit log of every notification sent to Telegram to ensure deliverability tracking and historical traceability.

| Column | Header | Type | Format / Constraints | Example Value | Description |
| :---: | :--- | :--- | :--- | :--- | :--- |
| **A** | `dispatch_id` | UUID | Standard v4 UUID | `f81d4fae-7dec-11d0-a765-00a0c91e6bf6` | Unique dispatch identifier. |
| **B** | `timestamp` | Timestamp | ISO-8601 | `2026-10-31T21:40:15+08:00` | Exact moment notification was posted. |
| **C** | `threat_score` | Integer | `0` to `100` | `78` | Computed composite escalation score. |
| **D** | `alert_level` | String | `ELEVATED`, `CRITICAL` | `CRITICAL` | Escalation classification. |
| **E** | `sectors_active`| String | Comma-delimited list | `SEC-01, SEC-02` | Sectors exhibiting verified anomalies. |
| **F** | `gemini_summary`| String | Text (2–3 sentences) | `Commercial air traffic diverted...` | Tactical synthesis generated by AI. |
| **G** | `telegram_msg_id`| Integer | Valid Telegram message ID | `8421` | Returned ID from Telegram API response. |

## Tab 5: `diplomatic_audit`
Hash cache used to prevent repeated alerts on static diplomatic advisories.

| Column | Header | Type | Format / Constraints | Example Value | Description |
| :---: | :--- | :--- | :--- | :--- | :--- |
| **A** | `hash_id` | String | SHA-256 or MD5 string | `e3b0c44298fc1c149afb...` | Hash of XML item title + pubDate. |
| **B** | `timestamp` | Timestamp | ISO-8601 | `2026-10-31T18:00:00+08:00` | When advisory was first parsed. |
| **C** | `feed_source` | String | `US_STATE_DEPT`, `UK_FCDO` | `US_STATE_DEPT` | Issuing government agency feed. |
| **D** | `item_title` | String | Full title string | `Philippines Travel Advisory - Level 4` | Raw headline text. |
| **E** | `flagged_term` | String | Exact keyword detected | `ordered departure` | Specific legal tripwire phrase identified. |
